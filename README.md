# Mr. Chris Lee — Portfolio

Modern Next.js portfolio converted from the WordPress (RyanCV) site at [chrislee.site](https://chrislee.site).

## Stack

- **Next.js** (App Router)
- **React** + **TypeScript**
- **Tailwind CSS**
- Static assets from the original WordPress media library

## Sections

- About (bio, services, tools, testimonials, fun facts)
- Resume (experience, education, skills, languages)
- Works (filterable project gallery with live links)
- Blog
- Contact (+ products teaser)

## Local development

```bash
cd portfolio-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Connected to **GitHub** and **Vercel**. Custom domain: `chrislee.site` (point DNS to Vercel).

## Project location

Always keep this app in:

`My Portfolio:VC/portfolio-app`
